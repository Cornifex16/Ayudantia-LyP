# Ejemplo de Autoría

Este archivo puede usarse para dividir las tareas entre los distintos integrantes, pero también sirve para dejar un registro de quien se encarga de que cosa. De esta manera se puede evaluar si hay alguien que este trabajando en exceso o que este trabajando de forma escasa, permitiendo una redistribución de los roles.

Les tengo dos plantillas que pueden usar para organizar su autoría. Sobra mencionar que estos son sugerencias y que pueden implementar otras formas de organizarse, lo importante es mantener lo limpio y claro del archivo.

## Separado en personas

**Trabajador_1**:
- diseño de movimiento
- sistema de puntuación
- sistema de ranking
- ...

**Trabajador_2**:
- diseño de niveles
- reglas adicionales del juego
- manejo de estructuras
- ...

**Trabajador_3**:
- Validación de niveles
- Encargado de pruebas y depuración
- Documentación
- ...

## Separado por tareas

- **diseño de movimiento**: Trabajador_1
- **diseño de niveles**: Trabajador_2
- **sistema de puntuación**: Trabajador_1 y Trabajador_2
- **Encargado de pruebas y depuración**: Trabajador_3
- ...
