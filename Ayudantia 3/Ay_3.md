## Paradigma imperativo

El paradigma imperativo es bastante similar a código assembly, es un solo archivo que carece de funciones o loops, en este paradigma la unica manera de repetir una accion es hacer un ```goto```, esta instruccion efectua un salto a la linea que tiene el "tag" especificado.

## Paradigma estructurado

Aca se insertan por primera vez los loops como formas de estructura, capaces de poder simplificar la lectura de código, ya que es mas logico, ademas que permite añadir mas código que antes al simplificar loops complejos como el goto. Las estructuras basicas de este paradigma son las secuencias(instrucciones normales), las selecciónes(```if```) y las iteraciones (ciclos ```while``` y ```for```).

## Paradigma procedimental

Aca se añaden los procedimientos a la hora de programar, capaces de englobar instrucciones complejas, pero que se repiten a lo largo del código con ligeras variaciones. Nace el manejo de memoria como se conoce actualmente aca, pudiendo trabajar con variables globales y variables en memoria.

## Paradigma modular

Este paradigma plantea que se pueden ahora encapsular códigos enteros en librerias externas, de esta manera se limpia el código que hay en el archivo y permite organizar mejor partes del código que podrian ser tareas independientes.

## Actividad

El archivo correccion contiene dos partes, una es código que tenemos que saber identificar donde estan sus variables en memoria, la otra es código con errores con el objetivo de que ustedes lo arreglen bajo cierto paradigma. Para el caso de la correccion de código se pide quitar el auto corrector de vscode, o en su defecto, abrirlo en otro programa, como bloc de notas o similar.
